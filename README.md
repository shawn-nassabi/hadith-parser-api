# hadith-parser-api


Running test.py retrieves 10 random hadith from the kaggle dataset in the datasets folder and prints the Arabic متن and سند and the corresponding full narrator names for each حدیث.
To run test.py follow the steps below:
1. At the root directory, run: uvicorn main:app --reload
2. Open a separate terminal window/tab at the root directory, then run: python test.py
